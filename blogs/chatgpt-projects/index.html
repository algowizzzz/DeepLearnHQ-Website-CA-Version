ChatGPT Projects: What They Are and How to Use Them (2026)

Short answer: Projects are ChatGPT's way of keeping related chats, uploaded files, and custom instructions together in one workspace — so it remembers the context of an ongoing piece of work instead of starting cold each time. Here's what they do, how to set one up, and where they shine.

What are ChatGPT Projects?

A Project is a folder with a memory. Inside it you can group multiple chats, upload reference files, and set custom instructions that apply to everything in that Project. Every conversation there shares that context — ideal when you're returning to the same task repeatedly.

How to set one up

  1. Create a new Project and name it for the work (e.g., "Q3 Marketing" or "Thesis").
  2. Add custom instructions — the role, tone, and rules you want applied every time.
  3. Upload reference files it should draw on (briefs, notes, data).
  4. Start chatting inside the Project — it now works with that shared context.

Best ways to use Projects

  • Ongoing work — a book, a course, a long report where context builds over weeks.
  • A recurring role — "my marketing assistant" with your brand voice baked into the instructions. See ChatGPT for business.
  • Study by subject — one Project per course, with your materials uploaded. See ChatGPT for students.

Availability & tips

Project features and limits vary by plan and change over time (see ChatGPT plans). Tip: keep instructions specific and files tidy — a focused Project outperforms a cluttered one.
